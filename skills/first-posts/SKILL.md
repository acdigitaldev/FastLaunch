# Launch social posts

## Collect if not already known
- Product name and one-line description
- Target audience (specific)
- Biggest pain point the product solves
- Any launch offer (free trial, beta discount, lifetime deal, waitlist)
- Founder name (for personal-voice posts)

## Strategy: 3 posts per platform, 3 angles

| Angle | Hook type |
|-------|-----------|
| Problem | "The problem with [X] is..." |
| Story | "6 months ago I was struggling with [X]..." |
| Proof | "We just hit [milestone]..." |

Use frameworks from references/post-templates.md. Customize with real details — never use placeholder text in output.

## Platform rules

Instagram: hook on line 1, 5-8 sentences with line breaks, 10-15 hashtags (mix sizes), end with CTA question.

Twitter/X: 280 chars max per tweet, threads labeled 1/ 2/ etc, hook-only first tweet, CTA + link last.

LinkedIn: 2-6 word hook then line break, personal story body, 3 hashtags max at end only, human tone not corporate.

Threads: conversational, max 500 chars, casual/hot take, no hashtags needed.

## Output format
For each post:
[PLATFORM] — Post [N] ([Angle])
[Full copy]
Suggested posting time: [day/time]

## Posting schedule
- Launch day: all 4 Problem posts within same 2-hour window
- Day 3: all Story posts
- Day 7: all Proof posts

After generating, ask: "Want me to export these to a content calendar?"
